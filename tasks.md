# Tasks for AITEST-1: Visualización de Hora Actual en Página Estática

## Task Breakdown

### Task 1: Create HTML Structure
- **Description**: Create the basic structure of `index.html` with a centered title "Current Time" and a `<div>` element to display the time.
- **Deliverable**: HTML skeleton with proper semantic tags.

### Task 2: Add Inline CSS Styling
- **Description**: Apply inline CSS to center the content, set a readable sans-serif font, and ensure high contrast for readability.
- **Deliverable**: Styled HTML with centered layout.

### Task 3: Implement JavaScript for Time Display
- **Description**: Use vanilla JavaScript to:
  1. Fetch the current time using the `Date` object.
  2. Format the time in 24-hour format (`HH:MM:SS`).
  3. Display the time in the `<div>` element.
- **Deliverable**: Functional time display.

### Task 4: Add Real-Time Updates
- **Description**: Use `setInterval` to update the time every second.
- **Deliverable**: Time updates automatically without page reload.

### Task 5: Validate and Test
- **Description**:
  1. Open `index.html` in a modern browser.
  2. Verify the title and time display correctly.
  3. Confirm the time updates every second.
  4. Ensure the design is clean and accessible.
- **Deliverable**: Validated and tested `index.html` file.

---

## Dependencies
- All tasks must be completed in sequence.
- No external dependencies are allowed.

---

## Notes
- Ensure the solution is self-contained in a single file (`index.html`).
- Use minimal styling to meet the requirements.
