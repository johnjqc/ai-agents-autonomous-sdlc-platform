# Quickstart: Current Time Display

## Execution

1. Locate the file `index.html` in the project root.
2. Open the file using any modern web browser (Double-click or Drag-and-Drop).
3. Verify that the title "Current Time" is centered and the clock is updating every second.

## Test Scenarios

### Scenario 1: Visual Verification
- **Expected**: Title is "Current Time", font is sans-serif, layout is perfectly centered.
- **Action**: Inspect page layout on load.

### Scenario 2: Time Accuracy
- **Expected**: Time matches system clock and follows `HH:MM:SS` (24h) format.
- **Action**: Compare displayed time with OS system clock.

### Scenario 3: Dynamic Update
- **Expected**: The seconds digit changes every second.
- **Action**: Observe the clock for 5-10 seconds.
