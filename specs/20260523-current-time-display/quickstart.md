# Quickstart: Current Time Display

**Date**: 2026-05-23

## Overview

This feature provides a **static HTML page** that displays the current time in a 24-hour format (`HH:MM:SS`) and updates automatically every second. No installation or setup is required beyond opening the file in a modern web browser.

## Testing the Feature

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge).
- No additional software or dependencies.

### Steps to Test

1. **Open the File**:
   - Navigate to the directory containing `index.html`.
   - Open `index.html` in your preferred web browser.

2. **Verify the Layout**:
   - Ensure the title "Current Time" is centered on the page.
   - Ensure the time is displayed in 24-hour format (e.g., `14:35:08`).

3. **Verify Real-Time Updates**:
   - Stay on the page for at least 10 seconds.
   - Observe that the time updates automatically every second.

### Edge Cases to Test

- **JavaScript Disabled**:
  - If JavaScript is disabled in the browser, the time will not update automatically, but the initial time should still be displayed.

- **Browser Compatibility**:
  - Test in multiple modern browsers to ensure consistent behavior.
