# Current Time Display Constitution

## Core Principles

### Principle 1: Minimal Self-Contained HTML
The solution must be a single self-contained file (`index.html`) using HTML5, inline CSS3, and vanilla JavaScript.

### Principle 2: Functional Requirements
- Centered title "Current Time".
- 24-hour format (HH:MM:SS).
- Auto-update every second.

### Principle 3: Design Constraints
- Readable sans-serif font.
- Clean background, high contrast text.
- Centered main container (vertically and horizontally).

## Technical Specifications
- File: `index.html`.
- Tech: HTML5, CSS3 (inline), JS (vanilla, `Date` object).

## Governance
Minimal PoC requirements. Versioning follows semantic rules.
