# Current Time Display Constitution

## Core Principles

### Principle 1: Single Self-Contained File
The solution must be implemented as a **single self-contained file** (`index.html`) with no external dependencies. This ensures portability and simplicity.

### Principle 2: Vanilla Technologies
The solution must use **HTML5, inline CSS3, and vanilla JavaScript** to ensure compatibility and avoid unnecessary complexity.

### Principle 3: Real-Time Updates
The displayed time must update **automatically every second** using vanilla JavaScript (`setInterval` or equivalent).

### Principle 4: User Experience
- The page must display a **centered title** reading "Current Time".
- The time must follow the **24-hour format (HH:MM:SS)**.
- The design must use a **readable sans-serif font**, a **clean background**, and **high-contrast text** for readability.
- The main container must be **centered both vertically and horizontally**.

## Technical Specifications

- **File**: `index.html` (single file, no external dependencies).
- **Technologies**: HTML5, inline CSS3, vanilla JavaScript (`Date` object).
- **Behavior**: Real-time updates every second using `setInterval` or equivalent.
- **Design**: Clean, minimal, and responsive layout.

## Governance

This constitution defines the **minimum requirements** for the PoC. Amendments are allowed for **clarity or correctness**, but no additional constraints will be added.
